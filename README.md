Project Title

Lakshmi Shopping Mall Receipt Generator

Project Overview

Lakshmi Shopping Mall Receipt Generator is a web-based billing application developed using HTML, CSS, and JavaScript. The project is designed to generate digital shopping receipts quickly and efficiently after a customer purchases products from a shopping mall or store.

The system allows users to enter customer details, product information, quantity, price, GST percentage, and discount percentage. After entering the details, the application automatically calculates the subtotal, discount amount, GST amount, and final total bill. It then generates a professional receipt that can also be printed.

The project features a modern glassmorphism user interface with a shopping mall background design to provide a professional appearance.
